This directory preserves the six approved Harnex naming outputs uploaded on 2026-09-01. The H Bridge Core symbol itself is not reinterpreted by these files: the canonical symbol remains the approved PNG mark inherited from the existing identity.

Reference variants:

- `harnex-lockup-light.png` — primary light horizontal lockup with payoff.
- `harnex-lockup-dark.png` — primary dark horizontal lockup with payoff.
- `harnex-lockup-compact-light.png` — compact light lockup without payoff.
- `harnex-lockup-compact-dark.png` — compact dark lockup without payoff.
- `harnex-wordmark-light.png` — light-surface Harnex wordmark.
- `harnex-wordmark-dark.png` — dark-surface Harnex wordmark.

Canonical product consumers must reference the corresponding named files under `../../master/`, not this provenance directory.
