# Bounded product references

Harness is code-first. The durable reference set is intentionally small:

- `docs/harness-ux-ui-implementation-plan.md` — primary surfaces, states and acceptance criteria;
- `docs/features/phone-app-architecture.md` — connected application state/effect/navigation boundary;
- `docs/design-system.md` — shared Compose components and semantic token ownership;
- `docs/harness-brand-guidelines.md` — brand intent and product language;
- `ui/design-system` Compose previews — executable dark/light component references.

Generated screenshot matrices, videos and traces are evidence artifacts, not design sources of truth.
